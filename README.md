# Vermont Home Search — Richmond + Milton, 500 ft+

Static site (no build step) listing single-family homes with 3+ beds, 1.5+ baths and a garage, in move-in condition, within 45 minutes' drive of **both** Richmond and Milton, Vermont, above 500 ft elevation.

- `index.html`, `style.css`, `app.js`: the site (Leaflet + OpenStreetMap map).
- `data.json`: listing data, regenerated daily from Redfin. Daily updates change only this file.

Data: Redfin (listings and photos), OSRM (drive times), USGS 3DEP (elevation).
